01 · MonoFS (247 test suites)

Virtual monorepo &
storage fabric.

Separates metadata (monofs-server Pebble DB), content (monofs-fetcher + Packager S3/GCS), and coordination (monofs-router) while embedding KVS, Zoekt, OCI v2, Bazel cache, and Doctor's logengine.

Client Data Path

Direct HRW reads & NutsDB overlays

monofs-client builds a local Rendezvous ring from router topology and routes Lookup, ReadDir, and Read directly to storage nodes without hitting the router.

  • Local edits stay isolated in NutsDB; --headless serves the identical overlay over session.sock with no /dev/fuse or SYS_ADMIN.
  • monofs-session push groups commits per repo and opens PRs/MRs; partial multi-repo failures cleanly revert commits rather than force-pushing.
Shared Fabric Planes

Reserved namespaces & logengine

Three reserved namespaces — guardian/, guardian-system/, and doctor/ — run versioned CAS storage, Parquet+Bluge telemetry chunks, and SQL federation inside the same cluster.

  • OCI v2 registry (:5000) and Bazel AC/CAS (:9092) reuse MonoFS replication and cluster tokens.
  • monofs-pipeline-worker executes affected DAG builds filtered through a strict safe env allowlist.

02 · Guardian (223 test suites)

Zero-DB intent
control plane.

Compiles YAML Partition and Intent manifests into dependency DAGs, detects drift, and dispatches tasks through CAS lease files with no inbound worker sockets.

Intent State Machine

Compile → Check → Diff → Apply → Archive

Every mutation carries a MutationContext (PrincipalID, Reason, CorrelationID) and writes immutable manifests/logs under /.archive/<partition>/<intent>/.

Invalid→ Blocked→ Ready→ Checking→ Diffing→ Applying (5m lease)→ Healthy/ DriftedLocked/ Observed (read-only)
  • 5 Native Pushers: GCP (OpenTofu + Cloud Asset Inventory), AWS (TypeScript CDK + CloudFormation), Kubernetes, Docker, and Local server.
  • Virtual Sets & Sticky Exclusions: guardianctl sets unassign writes sticky exclusions so manifest reconciles never silently re-attach removed partitions.

03 · Doctor (192 test suites)

Privacy funnel &
unified query API.

Ingests OTLP traces, logs, and metrics through a pre-WAL sanitization funnel into MonoFS logengine, paired with Sentinel alerting and 150k-target multi-cloud federation.

Ingest & Alerting

43.8k rec/s OTLP & Sentinel rules

doctor-ingest scrubs keys and HMAC-tokenizes PII/PCI before writing to per-signal fsync WAL buffers. doctor-rules elects a leader via 30s MonoFS CAS lease, while Sentinel fingerprints PromQL/Guardian/AWS alerts for Nightwatch.

Query & Federation

Grafana native + DuckDB SQL

Exposes Prometheus, Loki, Tempo, and POST /v1/sql/query with oauthPassThru ACL checks. Singleflight deduplication serves 1,005 ops/s at p95 22 ms (1,888 ops/s at 2,000 offered RPS).

04 · Agent & Nightwatch (19 test suites)

Dual-persona tool loop & shadow triage

Routes turns between Otto (50+ live tools across Guardian/Doctor/MonoFS/LB-Edge behind confirm=true) and Steve (workspace-only diffs in MonoFS overlay, blocked from mutating infrastructure). Nightwatch runs read-only on :8091, polling Sentinel every 30s into an append-only hash-chained SQLite ledger.

05 · LB-Edge (8 test suites)

Zero-DB L4 TCP routing & passive breakers

Watches Kubernetes Endpoints annotations (guardian.intent/expose, external-port) via k8s-agent, selecting matching Service ports on multi-port Pods. The TCP proxy syncs :18081/services every 2s, trips a passive breaker after 3 dial failures, and drains removed backends cleanly to zero connections.

06 · sqlagregator (14 test suites)

Two-phase
federated SQL.

A zero-driver core library (pulling only yaml.v3) with separate Go modules for each cloud dialect and pure-Go hash aggregation in the coordinator.

Execution Pipeline

AST → Two-Phase Planner → Dialect Pushdown → Pure-Go Merge

SELECT AST→ Catalog + Time-Shard Prune→ Coverage Check→ 5 Dialect Emitters→ Pure-Go Hash Merge
  • Driver nuances handled cleanly: CloudWatch Omni retries session-name collisions with a process-unique suffix; Logs Insights emits FROM_UNIXTIME(...) windows because @timestamp is a string; ClickHouse binds attributes['guardian.partition'].
  • Fail-closed governance: MonoFS router enforces --sql-require-policy (default true) and fails with coverage_gap if a healthy shard is excluded without -allow-partial.

07 · Reusable Go storage crates

KVS, Packager & cfg.

kvs (9 test suites)

Raft versioned KV

Optimistic CAS, batch revisions, prefix-indexed ListDir (p95 0.27–0.72 ms), watches, hot/archive retention, and JSONL audit trails.

packager (8 test suites)

Indexed-Tail O(1) archives

Retrieves any file from S3/GCS in 2–3 byte-range calls without scanning; PathIndex shrinks 100K file indexes from ~6.2 MB to ~1.2 MB; auto-skips zstd on 20+ pre-compressed formats.

cfg (1 test suite)

Two-tier versioned config

Keeps newest 5 revisions hot in Raft KVS (/cfg/<app>/current) and compacts excess versions into encrypted packager cold archives while keeping directory manifests online.

08 · PKI, RBAC & Cloud Tooling

tlsx, k8s-top, aws & bootstrap.

tlsx (3 test suites) + compiled RBAC

Zero-restart SPIFFE mTLS & compiled ACLs

tlsx reads STRATA_TLS_* across Go gRPC servers and Agent's Python backend, re-reading leaf certs on mtime changes and verifying SPIFFE URI SAN allowlists. Guardian compiles RBAC partition/log/trace/SQL/MonoFS grants from base.yaml into one runtime bundle.

k8s-top · aws · strata

Multi-cloud deployment & bootstrap

k8s-top exports Guardian-tagged pod/container OTLP metrics; aws deploys MonoFS + Guardian onto ECS Fargate via TypeScript CDK; strata provides single-command kind bootstrap and application onboarding workflows.
