What is Strata?

Strata is an open-source, self-hosted infrastructure platform written primarily in Go across 13 public repositories. Five core engines — MonoFS, Guardian, Doctor, LB-Edge, and Agent — share one storage and control fabric backed by custom primitives for versioned Raft state (KVS), ChaCha20 archives (Packager), federated SQL (sqlagregator), and SPIFFE mTLS (tlsx).

Step 01 · Write

Direct HRW reads. Local NutsDB overlay. Headless or FUSE.

monofs-client computes HRW shard keys locally to read straight from Pebble storage nodes (:9000), while keeping edits isolated in a local NutsDB overlay — with --headless support for containers lacking /dev/fuse or SYS_ADMIN.

monofs-client --headless --router monofs:9090 \
  --overlay /var/lib/monofs/overlay --virtual-monorepo --writable

monofs-session diff
monofs-session commit -m "feat: ship payments service"
monofs-session push   # reverts per-repo on partial upstream failure

Leaves behind a ChaCha20 packager bundle, an explicit PR/commit, and a Zoekt index update.

Step 02 · Plan

Compile DAGs. Queue CAS tasks. Zero inbound worker ports.

Guardian validates intents and asset joins, writes desired state via CAS into MonoFS guardian/, and queues tasks under /.queues/<pusher>/. Pushers poll, claim a 5-minute lease, and run DIFF → CHECK → APPLY.

apiVersion: guardian/v1alpha1
kind: Partition
metadata:
  name: production
spec:
  intents:
    - name: database
      targetPusher: k8s-prod
    - name: api-server
      targetPusher: k8s-prod
      joins: [database]

guardianctl partition reconcile --partition production

Leaves behind versioned .state/intents/*.json, release logs, and immutable /.archive/ records.

Step 03 · Route

Endpoints auto-register. Multi-port Services pin cleanly.

LB-Edge k8s-agent watches Kubernetes Endpoints with 30s informer resyncs, matching pinned external ports against multi-port Services. The TCP proxy polls :18081/services every 2s and drains removed backends to 0 active connections.

metadata:
  annotations:
    guardian.intent/expose: "true"
    guardian.intent/service-name: "api-server"
    guardian.intent/external-port: "8090"

# proxy syncs :18081/services every 2s · 3 dial errors trip breaker
curl -s http://lb-edge:18081/services | jq '.services'

Leaves behind a live TCP listener, passive circuit-breaker state, and Prometheus metrics on :19090.

Step 04 · Observe

Pre-WAL HMAC privacy. Parquet/Bluge storage. Two-phase SQL.

OTLP signals hit doctor-ingest (:4317/:4318), pass secret redaction and HMAC-SHA256 tokenization before WAL fsync, and land in HRW-sharded Parquet+Bluge chunks. doctor-query (:18080) runs native APIs, PromQL/LogQL/TraceQL, and federated SQL.

Nightwatch (inside Agent)

Shadow-mode triage.
With receipts.

Nightwatch is a headless shadow-mode SRE capability inside Agent — not a sixth engine and never given write keys. It polls Sentinel every 30s, treats telemetry as untrusted data, and builds an append-only hash-chained incident ledger.

  • Zero mutations, zero shell. No Guardian, Doctor, or Sentinel write calls; LLM summarizes evidence only.
  • Verifiable receipts. Every evidence row records exact query, time window, source, and result SHA hash.
  • Honest escalation threshold. Confidence below 0.5 (NIGHTWATCH_ESCALATION_CONFIDENCE) or cross-partition causes trigger escalation/handoff.
  • Reviewable Steve diffs. Improvement proposals open a diff in the MonoFS overlay — never auto-committed.

Candid Engineering Notes & Trade-Offs

What Strata deliberately does not hide

  • Pre-1.0, single-maintainer stack: Built in public by @radryc; interfaces still evolve and you own upgrades, capacity planning, and the 03:00 pager.
  • FUSE is a practical POSIX subset: Locking and mmap semantics are limited; use --headless session-socket verbs in restricted containers. Experimental C kernel module is not the supported path.
  • No magic automatic rollback: Failed applies record rollbackTo/rollbackReason and preserve the pushed manifest for retry; restoring a prior archived tag is an explicit operator action.
  • Scoped federation by design: Unscoped fleet queries across 150k targets return HTTP 422; there is no central rollup store, and metrics remain intentionally platform-visible without per-partition filtering.

Engineering Q&A

The hard questions
engineers ask first.

Concise, verifiable answers linked directly to the deep-dive pages and source repositories.

What is Strata?

Strata is an open-source, self-hosted infrastructure platform spanning 13 public repositories (734 test files). Five engines — MonoFS, Guardian, Doctor, LB-Edge, and Agent — share one storage and control fabric so source code, desired state, traffic, telemetry, and assistance keep the same context.

What are the five engines in Strata?

MonoFS is the source and storage fabric. Guardian is the zero-DB deployment control plane. Doctor is the privacy-first observability plane. LB-Edge is the L4 traffic plane. Agent is the approval-gated assistance plane. Nightwatch is a shadow-mode SRE capability inside Agent, not a sixth engine.

Does Strata use an external database for deployments?

No. Guardian uses MonoFS and embedded Raft KVS as a filesystem-as-database control plane. Partitions, intents, 5-minute task claim leases, and deployment archives are versioned CAS files, with no inbound deployment socket to pusher workers.

Does Strata replace Prometheus and Grafana?

Strata replaces the fragmented storage and glue layer, not the interfaces. Doctor ingests OTLP and exposes Prometheus, Loki, Tempo, and federated DuckDB SQL APIs so existing Grafana dashboards keep working with per-user OAuth token pass-through.

How does Strata scale observability across multi-cloud fleets?

Doctor includes a scoped federation controller tested against 50,000 pushers and 150,000 account-region targets, using 500-target SHA-256 catalog shards, atomic pointer hot-swaps, 256 AES-256-GCM token shards, and explicit HTTP 422 rejection for unscoped broad queries.

How does sqlagregator federate SQL across clouds?

sqlagregator runs two-phase AST rewrites over Go's database/sql driver using sqlparser and CockroachDB's parser. Queries scatter across registered AWS, GCP, and PostgreSQL engines, push down partial GROUP BY / HAVING aggregates, merge globally, and resolve tenant RBAC + OAuth tokens end-to-end.

How does Strata keep telemetry private?

Doctor runs a one-way privacy funnel before records touch the write-ahead log or storage. Secret keys, bearer tokens, and JWTs are redacted; identity, PII, and Luhn-validated PCI fields are replaced with per-tenant deterministic HMAC-SHA256 tokens.

Does Strata work with GCP, AWS, and on-prem Kubernetes?

Yes. Guardian ships native pushers for GCP (OpenTofu + Cloud Asset Inventory), AWS (TypeScript CDK + CloudFormation/CloudWatch), on-prem Kubernetes, Docker, and a local server using the same partition and intent model.

What is Nightwatch?

Nightwatch is a shadow-mode SRE capability inside Agent. It polls Sentinel alerts every 30 seconds, gathers read-only Doctor and Guardian evidence into a hash-chained SQLite ledger, and escalates low-confidence or cross-partition causes without mutating infrastructure.

How do I install and run Strata locally?

Clone github.com/radryc/strata and run ./scripts/bootstrap.sh up with Docker BuildKit, kind, kubectl, Go 1.26+, and OpenSSL installed. The script clones sibling repos, builds the engines, deploys Authentik SSO, and boots the full local stack.

Is Strata free and self-hosted?

Yes. Strata is licensed under Apache-2.0 with no hosted tier, seat pricing, or usage meter. Every component runs in your own kind cluster, Kubernetes environment, or cloud account.

What are the honest boundaries today?

Strata is pre-1.0 and maintained by one developer (@radryc). FUSE is a practical POSIX subset, LB-Edge is L4 TCP only, failed applies record rollback metadata rather than reversing automatically, and you own upgrades and on-call.
