# Strata Platform Hub

> **Start here:** [`github.com/radryc/strata`](https://github.com/radryc/strata) is
> the umbrella repository — the front door, component map, and bootstrap notes
> for the whole project. This repo is the landing page for `stratasre.com`.

> **New:** the static landing page for `stratasre.com` lives in
> [`landing/`](landing/) — see [`LANDING.md`](LANDING.md) for Cloudflare Pages
> deployment. The Hugo site described below is the legacy hub.

Landing page for the Strata distributed infrastructure platform — an open-source
project built and maintained in the open by one developer. Covers MonoFS,
Guardian, Doctor, Agent, LB-Edge, and more.

## Quick Start

```bash
hugo server -D
```

Open http://localhost:1313 in your browser.

## Build

```bash
hugo --minify
```

Output goes to `public/`.
